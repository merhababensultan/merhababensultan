# Sultan

Java ve Node.js ile backend geliştirme üzerine çalışan bir geliştiriciyim. Küçük projeler geliştirerek daha düzenli kod yazma, temel API tasarımı ve problem çözme becerilerimi geliştirmeye odaklanıyorum.

## Çalıştığım teknolojiler

| Alan | Teknolojiler |
|---|---|
| Backend | Java, Node.js |
| Dil | JavaScript |
| Araçlar | Git, GitHub |

## Şu an odaklandıklarım

Java ile backend temellerini pekiştiriyor, Node.js ile küçük API ve Discord bot projeleri üzerinde pratik yapıyorum. Öğrenme sürecimde kodu anlaşılır tutmaya ve tamamladığım projeleri düzenli biçimde belgelemeye önem veriyorum.
